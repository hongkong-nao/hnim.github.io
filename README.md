# HNIM · QQ 风格局域网聊天系统（PHP）

纯 PHP + MySQL/SQLite 实现，无框架、无 Composer 依赖，整个目录可以直接拷进 U 盘随身带。

---

## 快速开始

### 方式 A：U 盘便携运行（推荐）

```
1. 下载免安装版 PHP → 解压到  HNST-USB\php\   （要能看见 php.exe 和 ext\）
2. 双击  HNST-USB\启动聊天.bat
3. 浏览器打开首页即可（U 盘模式默认走 SQLite，不需要 MySQL）
```

### 方式 B：普通虚拟主机

```
1. 上传整个 hnim 目录到网站目录
2. 浏览器访问首页 —— 自动建库建表
3. 访问 http://你的域名/hnim/admin.php 配置 SMTP 后即可注册
```

### 方式 C：本地命令行

```bash
# PHP 内置服务器（必须带 router.php，否则 .htaccess 不生效，敏感目录会被直接下载）
set PHP_CLI_SERVER_WORKERS=12
php -S 0.0.0.0:8899 router.php
# 浏览器打开 http://127.0.0.1:8899/
```

> **Windows 用户注意**：`PHP_CLI_SERVER_WORKERS` 只在 Linux/macOS 上生效，Windows 的内置服务器始终是**单线程**的。
> 程序已自动识别这种情况：单线程时不做 20 秒长轮询，改成每 1.5 秒短轮询，
> 这样多个人的浏览器同时开着也不会互相卡死。若部署在 Apache / Nginx /宝塔 上，则照常使用长轮询，消息更快到达。

### 两个数据库

| 模式 | 数据放在哪 | 说明 |
|---|---|---|
| **单库（默认）** | 一个库 | 会话、消息、账号全在一起，最省事 |
| **双库** | 账号库 + 聊天库 | 账号资料放 A 库，会话/消息/成员/输入状态/收藏/入群申请放 B 库。适合聊天记录量大、想把记录单独备份或单独放另一台机器 |

双库模式下，聊天表和账号表**不能 JOIN**，程序内部统一走「先查聊天表 → 再按用户 id 批量补用户信息」两步走，功能完全一致。SQLite 便携模式永远是单库。

### 两种数据库类型

| 模式 | 何时用 | 数据存放 |
|---|---|---|
| **MySQL / MariaDB** | 局域网 / 网站多人同时使用 | 服务器数据库 |
| **SQLite 便携模式** | U 盘随身带、完全离线 | `data/hnim.sqlite`（跟着 U 盘走） |

## 自动建库建表

首次访问时自动完成，且重复访问无副作用：

1. 库不存在 → 自动 `CREATE DATABASE`（账号库和聊天库各自独立判断）
2. 表不存在 → 整张建出来，按「账号表进账号库、聊天表进聊天库」分开落位
3. 字段缺失 → 自动补齐
4. 索引缺失 → 自动补齐，含 `users.username`、`friends(user_id,friend_id)` 唯一索引
5. 全部确认无误后写锁文件（`schema.db.lock` / `schema.chat.lock`），之后不再重复检查

手动触发一次（可选，方便看结果）：

```bash
php -r "require 'app/core.php'; var_dump(hnim_db()); var_dump(hnim_chat_db());"
```

### 手动强制重跑

```bash

```

或者删掉锁文件强制重跑一遍：


  - 保留时长可切 1 / 3 / 6 / 12 / 24 个月，切换后自动刷新统计（多少条、涉及多少个会话、时间范围）

- 密码 `password_hash` 加盐哈希
- 全部 SQL 使用预处理语句
- CSRF Token 校验、Session 固定攻击防护
- 配置文件与数据目录访问保护
- 上传目录禁止执行脚本
- 登录日志留存最近 500 条

## 常见问题

**Q：打开首页跳出一张「连不上数据库」的页面？**
程序把数据库地址、库名、账号、密码都写在 `config/database.php` 里了。
页面上的方框里是 MySQL 的原始报错，按单子逐项查：

1. 地址：`localhost` 指本机 MySQL；`191.40.37.15` 是聊天库所在的另一台机器，
   要确认那台机器的防火墙 / 安全组放行了 3306，而且 MySQL 允许远程连接。
2. 库名 / 账号 / 密码有没有打错（区分大小写）。
3. 提示没有建库权限时，手工执行：
   ```sql
   CREATE DATABASE `vhsc8ff30f3` DEFAULT CHARACTER SET utf8mb4;
   CREATE DATABASE `vhsb1f165f9` DEFAULT CHARACTER SET utf8mb4;
   ```
   建完刷新即可，剩下的表程序会自己建。

改完**刷新页面就行，不用重装**。

**Q：打开网站跳出一张「连不上数据库」的页面？**
这不是程序坏了，是数据库没连上。页面上已经写清楚原始报错，按提示核对
`config/database.php` 里的地址 / 库名 / 账号 / 密码，然后**直接刷新页面**即可，
不需要重装 —— 程序会自动补建缺库和缺表。

两个最常见的原因：
- 账号库写的是 `localhost`，指**网站所在那台机器**的 MySQL，不是你的电脑。
- 聊天库在 `191.40.37.15`（另一台机器），需要那台机器的防火墙 / 安全组放行 3306，
  且 MySQL 允许远程登录（`bind-address` + 授权里带 `%`）。

**Q：提示「找不到数据库驱动」/ `could not find driver`？**
`pdo_mysql` 没启用。在 `php.ini` 里去掉这两行前面的分号，然后重启服务器：
```ini
extension=pdo_mysql
extension=pdo_sqlite
```

**Q：图片发不出去 / 上传失败？**
上传限制 50MB。需要同时满足 `php.ini` 的 `upload_max_filesize`、`post_max_size`
和 Web 服务器的 `client_max_body_size`。

**Q：注册页面提示「管理员还没有配置好邮件服务」？**
去 `admin.php` → **邮件设置**，把 SMTP 填好并点「保存」再「测试发信」。
需要这几项：服务器地址、端口、加密方式（465 用 `SSL`，587 用 `STARTTLS`，25 一般用 `无`）、
发信邮箱账号、邮箱授权码（不是登录密码，是邮箱后台生成的授权码/专用密码）、发件人邮箱。
QQ 邮箱的授权码在「设置 → 账户 → POP3/SMTP 服务」里开通后生成。
**SMTP 没配好之前别人是注册不了的**，这是为了防止有人批量注册小号。

**Q：后台密码忘了？**
最简单的办法：删掉 `config/admin.php`，再打开 `admin.php` —— 程序会用默认账号
`huinao` / `hn112233` 重新生成一份，登录后立刻改掉。

想手动改的话，直接编辑该文件里的 `admin.user` 和 `admin.pass_hash`，
`pass_hash` 用下面这行命令生成：

```bash
php -r "echo password_hash('新密码', PASSWORD_DEFAULT);"
```

**Q：搜索框为什么自己变灰了？**
这是故意的：3 秒没有输入就变灰，表示它闲置了。点一下或打一个字马上恢复。

**Q：消息要过几秒才收到？**
长轮询最长等待 20 秒，服务器一有新消息会立刻返回。正常情况下是秒级。
如果一直收不到，检查反向代理是否开启了响应缓冲（Nginx 的 `proxy_buffering off;`）。
用 U 盘上的 `启动聊天.bat`（Windows 内置服务器）时是 1.5 秒轮询，最多延迟约 1.5 秒。

**Q：能放公网吗？**
建议不要。本程序面向内网 / 小范围使用。放公网请务必配 HTTPS，并考虑加
nginx 的 `client_max_body_size 52m;` 与 `proxy_read_timeout 60s;`。

**Q：怎么备份？**
复制整个 `hnim` 文件夹即可。SQLite 模式要连 `data/` 一起复制。
双库模式下聊天库在另一台机器上，要单独备份那个库。
